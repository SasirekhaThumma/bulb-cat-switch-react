**Bulb and Cat Switch – React.js Project**

📌 **Project Overview**

The Bulb and Cat Switch is a simple interactive web application developed using React.js. It demonstrates how React state management works by allowing users to switch a bulb ON and OFF.

When the user clicks the ON or OFF button:
- The bulb image changes.
- The cat image changes.
- The switch status updates dynamically.

This project helped me understand React components, the `useState` Hook, event handling, and conditional rendering.

## ✨ Features

- Turn the bulb ON and OFF.
- Dynamically change bulb and cat images.
- Update the switch status based on user actions.
- Simple and user-friendly interface.
- Responsive layout.

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- HTML5

## 📸 Project Output

### Bulb Switched ON
When the user clicks the ON button, the bulb lights up, the cat appears with open eyes, and the status displays "Switched On".

### Bulb Switched OFF
When the user clicks the OFF button, the bulb turns off, the cat image changes, and the status displays "Switched Off".

## ⚙️ How to Run the Project Locally

Follow these steps to run the project on your computer.

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/bulb-cat-switch-react.git
```

### 2. Navigate to the Project Folder

```bash
cd bulb-cat-switch-react
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open in Browser

After running the command, Vite will display a local URL in the terminal.

Open the URL in your browser. Usually:

```text
http://localhost:5173/
```
